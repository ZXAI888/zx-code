# 1.2 Installation Guide

## Official Channels and System Requirements

Only download ZX Code from the [official website](https://zxai888.github.io/zx-code/).

| System | Minimum Version | Architecture |
|--------|-----------------|--------------|
| Windows | Windows 10 or later | x64 |
| macOS | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux | See distribution notes below | x64 / ARM64 |

## Prerequisites

### Install Node.js

The CLI tools managed by ZX Code (Claude Code, Codex, Gemini CLI) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

#### Windows

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

 ```bash
 node --version
 npm --version
 bash
# Install with Homebrew
brew install node

# Or use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Or use nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### Install CLI Tools

#### Claude Code

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install claude-code
```

**Option 2: npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install codex
```

**Option 2: npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install gemini-cli
```

**Option 2: npm**

```bash
npm install -g @google/gemini-cli
```

## Linux

### ArchLinux

Install using an AUR helper:

```bash
# Using paru
paru -S cc-switch-bin

# Or using yay
yay -S cc-switch-bin
```

### Debian / Ubuntu

1. Download `ZX-Code-v{version}-Linux-x86_64.deb` or `ZX-Code-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i ZX-Code-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### AppImage (Universal)

1. Download `ZX-Code-v{version}-Linux-x86_64.AppImage` or `ZX-Code-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x ZX-Code-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./ZX-Code-v{version}-Linux-*.AppImage
```

## Verify Installation

After installation, launch ZX Code:

1. The app window displays correctly
2. A ZX Code icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Auto Update

ZX Code includes built-in auto-update functionality:

- Automatically checks for updates on startup
- Displays an update prompt in the UI when a new version is available
- Click to download and install

You can also manually check for updates in "Settings > About".

## Uninstall

### Windows

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory

### macOS

- Move `ZX Code.app` to Trash
- Optional: Delete the configuration directory `~/.zx-code/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-switch

# ArchLinux
paru -R cc-switch-bin
```
