# ZX Code

[English](README.md) · [简体中文](README_ZH.md) · [日本語](README_JA.md) · [Deutsch](README_DE.md)

ZX Code 用于管理本地 AI 编程工具，可切换官方供应商，也可填写自己的 API 地址和密钥。支持 Windows、macOS 和 Linux。

[下载 ZX Code](https://zxai888.github.io/zx-code/)

## v4.0.39

v4.0.39 支持设置备份目录容量上限、复制供应商 API 密钥，并修复流式连接卡住时的故障切换和长时间运行时的内存占用。

v3.17.2 安装版可在「设置 → 关于」检查签名更新，便携版请从官网下载。
