# ZX Code

[English](README.md) · [简体中文](README_ZH.md) · [日本語](README_JA.md) · [Deutsch](README_DE.md)

Mit ZX Code lassen sich lokale KI-Entwicklungswerkzeuge verwalten, offizielle Anbieter auswählen und eigene API-Gateways einrichten. Unterstützt werden Windows, macOS und Linux.

[ZX Code herunterladen](https://zxai888.github.io/zx-code/)

## v4.0.39

Version 4.0.39 ergänzt ein Speicherlimit für Backups und eine Kopierfunktion für API-Schlüssel. Sie verbessert den Wechsel bei blockierten Streams und begrenzt den Speicherverbrauch bei langen Antworten.

Installierte Versionen ab 3.17.2 können unter Einstellungen → Über nach signierten Updates suchen. Portable Versionen erhalten das Update über die Downloadseite.
