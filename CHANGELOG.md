# Changelog

All notable changes to ZX Code will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## ZX Code v4.0.39

- Added a storage limit for backups and a copy action for provider API keys.
- Fixed failover for stalled streams and limited memory use during long responses.
- Kept the ZX Code data directory, official provider presets, custom gateways, and signed website updater.


## ZX Code v3.17.2

- Enabled signed in-app updates for installed builds and directed portable users to the ZX Code download page.
